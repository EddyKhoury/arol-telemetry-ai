# AROL Telemetry AI

Agentic AI system for analysis of telemetry from industrial AROL capping machines.

## Project structure

- `src/ingestion/` — data loading, validation, closure detection and event assembly
- `src/analytics/` — deterministic statistical analysis
- `src/agent/` — agent and tool integration
- `src/interface/` — reporting and user interface
- `tests/` — automated tests
- `docs/` — project specifications and documentation
- `data/` — development datasets
